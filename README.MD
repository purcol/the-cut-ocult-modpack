# not VidemanMC Modpack since 03.11.25
In was repository the modpack from our modded server is stored. I keep it in specific structure:
  `client/` - client.
  `server/` - server.
  `generic/` - content for both sides.

## Why?
Idk, why now, but it was for:
1. For the launcher to be able to download modpack without server part.
1. To speed up the upgrade process - it is not need to separate mods into client and server parts every time the modpack is being updated.

### What is `hash.txt` file?
This file was used by the [launcher](https://github.com/VidemanMC/launcher) to check if local files are outdated. (It never got finished tho)
